# MyFirstGolangProject

A simple Golang REST API for User Registration & Login using Echo Framework, JWT Authentication, and MySQL.

## ✅ Features

- User Registration
- User Login with JWT Token
- Password Hashing (bcrypt)
- MySQL Database
- Clean API Design using Echo Framework

---

## ⚙️ Requirements

- Go version 1.25
- MySQL Database
- VS Code (Optional)
- Postman (for API testing)
